
ΠΡΟΑΠΑΙΤΟΥΜΕΝΑ:
~Ο υπολογιστής θα πρέπει να έχει εγκατεστημένο Node.js.
~Το κινητό πρέπει να έχει την εφαρμογή Expo Go.
~Ο υπολογιστής και το κινητό θα πρέπει να είναι συνδεδεμένα στο ίδιο WiFi.


ΒΗΜΑΤΑ ΕΓΚΑΤΑΣΤΑΣΗΣ:
1. Δημιουργία του project
Στο terminal(Command Prompt, PowerShell κ.λπ.) τρέξτε με τη σειρά τις παρακάτω εντολές:
npx create-expo-app@latest matchspot --template blank
cd matchspot
npx expo install react-native-svg

2. Αντικατάσταση του App.js
Αντικαταστήστε το αρχείο App.js που υπάρχει ήδη μέσα στον φάκελο matchspot με το App.js
που ανεβάζουμε στο GitHub.

3. Εκκίνηση της εφαρμογής
Τέλος, στο terminal τρέξτε:
npx expo start

4. Σάρωση QR code
Θα εμφανιστεί ένα QR code στο terminal.
Σαρώστε το με την κάμερα του κινητού σας.
Θα ανοίξει αυτόματα η εφαρμογή Expo Go και θα φορτώσει το app.

ΣΗΜΕΙΩΣΕΙΣ:
Βεβαιωθείτε ότι ο υπολογιστής και το κινητό είναι στο ίδιο δίκτυο WiFi,
αλλιώς η σύνδεση δεν θα λειτουργήσει.
